Frequently Asked Questions

What formats is the book available in?

PDF and EPUB via direct purchase. Kindle format on Amazon. All formats included in the $9.99 price.

Is this the same as the free AI Learning Kit?

No. The free AI Learning Kit contains introductory materials. The Founders Complete Edition is a full 216-page practical guide that teaches you to install and run AI locally, build tools, create agents, and use AI responsibly — with complete privacy and no subscriptions.

Do I need a powerful computer?

No. Everything in this book runs on consumer hardware — MacBook Air, Windows laptop, Linux machine. The Hardware Guide chapter covers exactly what you need for your specific machine.

Does the book include access to code?

Yes. All purchasers receive access to a companion GitHub repository with reference implementations, code examples, specification documents, and supplementary materials. Apache 2.0 licensed.

100% of proceeds fund CivicOS Institute — a nonprofit building open-source tools for government transparency. Your purchase pays for code, not overhead.
